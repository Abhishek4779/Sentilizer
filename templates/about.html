About This Project

Sentilizer is a full-stack sentiment analysis web application that analyzes the emotional tone behind text — particularly tweets — using advanced Natural Language Processing (NLP) and Machine Learning (ML) models. It combines span Python, Flask, HTML, CSS, JavaScript, and SQLAlchemy to deliver accurate, real-time insights in a secure and responsive interface.

The core model was trained on over 1.5 million tweets using Logistic Regression and Multinomial Naive Bayes, where Logistic Regression achieved the best accuracy. Both the model (lg_reg.pkl) and TF-IDF vectorizer (tfidf.pkl) were deployed for real-time text analysis through a Flask API.

The backend integrates user authentication and database operations through Flask and SQLAlchemy, ensuring encrypted storage for user credentials. The frontend, designed using HTML, CSS, and JavaScript, provides an intuitive experience tailored for desktop users.

🎯

Tech Stack & Development

  • Python – Data processing & ML model training
  • Flask – RESTful backend API and app routing
  • SQLAlchemy – ORM-based secure database management
  • HTML, CSS, JavaScript – Responsive frontend UI
  • Scikit-learn – Model training and evaluation
🧩

System Design & Architecture

  • Machine Learning model (trained & serialized)
  • Flask backend (API endpoints for analysis & authentication)
  • Database layer (user management via SQLAlchemy)
  • Frontend interface (text input, prediction results, and UX design)
🔒

Security & Best Practices

  • Passwords stored using encryption
  • Validated user input and safe API calls
  • SQLAlchemy ORM to prevent SQL injection
  • Flask session management for user login control

Why Sentiment Analysis Matters

  • Brand Monitoring: Track how customers feel about your products and services in real time.
  • Market Research: Understand public opinion and trends to inform business strategies.
  • Customer Service: Identify and prioritize negative feedback to improve customer satisfaction.
  • Content Strategy: Measure audience reactions to optimize your content and messaging.
