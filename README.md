# 🧠 Sentilizer – AI-Powered Sentiment Analysis Web App

**Sentilizer** is an AI-powered sentiment analysis web application that classifies user input text as **Positive** or **Negative** and provides a **confidence score** for each prediction.  
It offers a secure and responsive interface for real-time sentiment analysis.

---

## 🚀 Features

- 🔐 **User Authentication:** Secure user login and sign-up functionality.  
- ⚡ **Real-Time Sentiment Analysis:** Instantly classifies text sentiment with confidence scores.  
- 🧱 **Secure Backend:** Built with Flask and RESTful API design principles.  
- 💻 **Responsive UI:** Clean and adaptive front-end built using HTML, CSS, and JavaScript.  

---

## 🛠️ Tech Stack

**Frontend:**  
- HTML  
- CSS  
- JavaScript  

**Backend:**  
- Flask  
- REST API  

**Database:**  
- SQLite (for local development)  
- PostgreSQL (for deployment)
